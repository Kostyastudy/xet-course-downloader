# 小鹅通课程下载器 · xet-course-downloader

把「小鹅通店铺里的课程」完整搬到本地：**读目录 → 下分片 → 合并成完整视频 → 下课件 → 整理成目录**。

一个**本地网页控制台** + 一个**极小的浏览器扩展**，零第三方 Python 依赖。

---

## v1.2 能干什么（三件新事）

| 新能力 | 怎么用 |
|---|---|
| **自由挑内容** | 课时列表支持关键字搜索、按类型筛选（视频/直播/课件）、按**专栏折叠分组**，每组可「全选本栏 / 清空」，还能一键全选 / 全不选 / 反选。大课包 187 节课也不至于挑花眼。 |
| **下载前预估体积** | 点「估算体积」，工具会抽样读 m3u8 分片实测码率，按中位数推算整节大小，几十秒就能算出整包多少 GB，并且实时显示**硬盘剩余空间够不够**。 |
| **配置不用改代码** | 保存目录、并发数、端口、估算线程等都能在页面上填，写进 `~/.xetdl/settings.json`，下次启动自动生效。 |

> 官方实测（某大课包 187 节课 / 176 个可估视频）：**40 秒算完，合计 135.3 GB**；
> 抽 52 节真实下载对比，估算合计 **57.6 GB vs 实际 51.6 GB，误差 +11.7%**（偏保守，方便提前留余量）。

## 它长什么样

```
┌──────────────┐   ①在已登录页面里读目录      ┌──────────────────┐
│  浏览器扩展   │ ─────────────────────────▶ │   本地服务        │
│  或控制台一行 │   只取目录 + 签名播放地址    │  127.0.0.1:8777  │
└──────────────┘                            └────────┬─────────┘
                                                       │ ②计划(JSON)
                                                       ▼
                                              ┌──────────────────┐
                                              │  网页控制台       │
                                              │  勾选课时/看进度  │
                                              └────────┬─────────┘
                                                       │ ③全部字节走本地
                                                       ▼
                                     ┌────────────────────────────────┐
                                     │  Python 下载器（零依赖）         │
                                     │  分片并发 → concat → ffprobe 自检 │
                                     │  → 课件下载 → 按名归档 → 索引      │
                                     └────────────────────────────────┘
```

**关键设计**：扩展/控制台桥**只负责取数**（目录 + 签名地址），**几十 GB 的实际流量、合并、校验、归档全走本地 Python**。视频分片与课件 CDN 直链免登录可下，所以浏览器不需要经手任何大文件。

**关键隐私**：扩展**不读取、不存储、不外传你的 Cookie / 账号信息**。它只是在你已登录的页面里，用浏览器本来就有的登录态调平台自己的接口。

## 两种装法（任选其一，可同时共存）

| | **路径 E · exe 版**（推荐新手） | **路径 P · Python 版** |
|---|---|---|
| 怎么起 | 双击 `XetDownloader.exe` | 双击 `一键启动.bat` 或 `python start.py` |
| 要装什么 | **什么都不用装**（ffmpeg 已内置） | Python 3.8+ 和 ffmpeg |
| 从哪拿 | GitHub [Releases](https://github.com/Kostyastudy/xet-course-downloader/releases) 页 | 本仓库源码 |
| 默认端口 | **8787** | **8777** |
| 配置文件 | `~/.xetdl-exe/settings.json` | `~/.xetdl/settings.json` |
| 窗口 | Edge 独立窗口（无地址栏，像 App） | 默认浏览器标签页 |
| 下载目录 | `~/小鹅通课程` | `~/小鹅通课程`（同一个） |

> exe **不在代码目录里**，去 Releases 页下载。Git 对单文件 >100 MiB 是硬拒绝的，
> 所以 exe 只能走 Release 附件（上限 2 GiB，下载流量免费）。

两种装法**共用同一份核心代码**（同一个 `xetdl/`），靠运行时检测自动分流，
所以两版可以**同时开着**，端口和配置各是各的，互不覆盖。

⚠️ **别同时下同一节课** —— 两版会各自写 `.segs` 分片目录，可能互相踩。
下不同的课、或者一前一后跑，都没有问题。

### exe 版首次运行

1. 从 Releases 下载 `XetDownloader.exe`（约 133 MB）
2. 双击。Windows 会弹「**Windows 已保护你的电脑**」→
   点「更多信息」→「**仍要运行**」。
   这是所有未签名 exe 的必经步骤（代码签名证书要花钱），不是中毒。
3. 会弹出一个黑色控制台窗口（里面滚的是下载日志）+ 一个像 App 的窗口（界面）。
4. 杀软若报「可疑」，选「允许」或把 exe 加进排除列表；也可以改用 `-onedir.zip` 版（误报率低）。

## 三步用法

### ① 装「取数桥」（只需一次）

下载器只负责搬字节；**「拿课程目录 + 签名播放地址」这一步必须在你自己已登录的小鹅通页面里执行**。两种方式任选：

**方式 A · 浏览器扩展（推荐）**

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目的 **`extension/`** 目录
   （**用 exe 版、手上没有这个目录？** 在控制台页面点「导出自带扩展（zip）」，
   解压后指向解压出来的 `extension/` 目录即可）
4. 登录你的小鹅通店铺页面，点工具栏里的扩展图标

> 扩展会自动探测本地服务：先试 8777（Python 版），再试 8787（exe 版），
> 谁在线就连谁，并把地址记住。想手动指定就在扩展弹窗里改「本地服务」那一栏。

**方式 B · 一行控制台命令（不想装扩展）**

在你**已登录**的小鹅通课程页按 `F12` → 控制台，粘贴：

```js
fetch('http://127.0.0.1:8777/bridge.js').then(r=>r.text()).then(eval)
```

执行后回到控制台页面刷新，就能看到课时列表了。
（换浏览器 / 换店铺要重来一次；想指定课程链接用
`fetch('http://127.0.0.1:8777/bridge.js?url=' + encodeURIComponent('你的课程链接')).then(r=>r.text()).then(eval)`）

> 扩展和控制台桥跑的是**同一份** `extension/content.js`（本地服务在 `/bridge.js` 下发它），
> 所以两条路的行为完全一致，不会出现「扩展能下、控制台桥不能下」这种跑偏。

### ② 挑内容（v1.2 大改进）

课程计划同步进来后，控制台会显示：

- **搜索框**：按课时名 / 专栏名即时过滤；
- **类型筛选**：视频 / 直播回放 / 课件，按需勾；
- **专栏折叠分组**：大课包自动按子专栏分组，每组标题旁显示「N / N 已选」，可单独「全选本栏 / 清空」；
- 顶部三个状态 pill：**已选课时数 / 估算或已知总体积 / 目标磁盘剩余空间**；
- 一键**全选 / 全不选 / 反选**。

想先看体积再决定下多少，点「**估算体积**」，几十秒后每节课后面会显示大小，标题栏显示合计；
如果超出磁盘剩余，页面会提示——**可以在看到体积之后倒回来改勾选，再开下载**。

### ③ 开下、看进度

点「**开始下载**」填保存目录即可。页面下方「任务进度」区实时显示每讲的进度条、日志和「打开目录」按钮。
任务可以随时取消；重跑同一门课会自动跳过已存在的视频（断点续跑）。

## 输出目录结构

单专栏课程保持扁平；**大课包**（一个专栏点进去是多个子专栏）会自动多套一层专栏目录，
每个专栏内部从 `01` 独立编号，总览文件也按专栏分节。

```
<保存目录>/
└── <课程名>/
    ├── 00_课程总览.md          ← 全部课时的索引表（视频/课件/状态）
    ├── 使用须知.md              ← 合规提示，随产物一起走
    ├── 下载计划.json            ← 本次下载计划，可给命令行模式复用
    ├── 01_大学物理/            ← 【仅大课包】子专栏目录
    │   ├── 01_第1讲/
    │   │   ├── 视频.mp4         ← 合并好的完整视频
    │   │   └── 课件/            ← 按文件名自动对号入座的课件
    │   └── 02_第2讲/
    └── 02_高等数学/
        └── 01_第1讲/ ...
```

小课包 / 单专栏课程不会多出这一层：

```
<保存目录>/
└── <课程名>/
    ├── 00_课程总览.md
    ├── 01_第1讲/ { 视频.mp4, 课件/ }
    └── 02_第2讲/ ...
```

课件会按**文件名里的日期 / 第 N 讲 / NN 课 / 第 N 章**自动分发到对应课时；同盘默认用**硬链接**，不额外占磁盘空间。
**旧版平铺目录里的视频会被自动找到并搬进新结构，不会重下。**

## 配置（不用改代码）

页面右上角「配置」区填完点保存即可，写入：

| 平台 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.xetdl\settings.json` |
| macOS / Linux | `~/.xetdl/settings.json` |

控制台页面会显示这个文件的实际路径和是否可写（`/api/health` 的 `settings_path`）。

| 键 | 默认值 | 说明 |
|---|---|---|
| `out` | `~/Downloads/小鹅通课程` | 默认保存目录 |
| `threads` | `10` | 单节课的分片并发数 |
| `jobs` | `2` | 同时下几节课 |
| `port` | `8777` | 控制台端口（改完要重启） |
| `host` | `127.0.0.1` | 监听地址 |
| `sizing_workers` | `4` | 估算时同时估几节 |
| `sizing_sample` | `8` | 每节抽样几个分片 |

**非法值会被静默丢弃**（例如 `threads: "abc"`、端口超出 1–65535），不抛异常也不会把配置写坏；
文件损坏时自动回退到默认值。改端口后需要重启服务。

## 平台接口实测结论（2026-11-17 真实抓包）

工具的取数逻辑全部基于对真实小鹅通店铺的实测，不是猜的。**哪些接口要登录、哪些不要**，这一节是整份文档里最该先读的：

| 接口 | 用途 | 免登录？ |
|---|---|---|
| `/xe.course.business_go.column.items.get/2.0.0` | 读专栏的课时列表 | ✅ **公开可读**，匿名也能拿全量 list |
| `/xe.course.business_go.courseware_list.get/2.0.0` | 读课件附件清单 | ✅ 免登录，CDN 直链 |
| `/xe.micro_page.category_good.get/2.0.0` | 读店铺商品清单 | ✅ 免登录（`category_goods_id` 必须是**字符串**） |
| `/xe.course.business_go.goods.info.get/2.0.0` | 读大课包商品信息 | ✅ 免登录，但参数名是 **`resource_id`**（传 `product_id` 报 `code:10 参数错误`） |
| `/_alive/v3/get_lookback_list?alive_id=…` | 直播回放 → 播放地址 | ❌ **需要登录**，未登录返回 `code:11302` |
| `/xe.course.business_go.video.mutli_line/1.0.0` | 录播 → 播放地址 | ❌ **需要登录**（AES-128 加密清单，约 30 分钟过期） |

**所以**：**目录和课件不用登录就能读全，只有「播放地址」这一步需要登录态**。
这也是为什么工具把取数拆成两段（`withUrls` / `withWare` 可单独开关）——
没登录也能先把「这门课有多少节、叫什么」看清楚。

**大课包（一个专栏点进去是多个子专栏）**：
`column.items.get` 对大课包会返回 `code:0` 但 `list` 为空，子专栏在 `goods.info.get` /
`resource.available.get` 里（实测 `other_list` 对某些大课包恒为空）。

**唯一可靠的路子是 `topic.items.get`**（v1.2 起接入）：

| 接口 | 参数 | 返回 |
|---|---|---|
| `/xe.course.business.topic.items.get/2.0.0` | `bizData[column_id]=p_xxx`、`page_size` | `data{total, list[]}`，`list` 里就是子专栏 |

它可以匿名调用。工具取数顺序是 **`topic.items.get` → `column.items.get` → `goods.info.get` → `resource.available.get`**，
哪一步先拿到子专栏就用哪一步；仍然保留**递归结构提取**（不依赖字段名）作为兜底。

## 体积估算准不准

估算不下载整个视频，而是**抽样读 m3u8 里的若干分片、读它们的 `Content-Length`**，再按中位数推整节大小。几个关键点：

- 分片行多为相对路径，**必须先 `urljoin` 补绝对地址**，否则抽样全 404、体积凭空翻倍；
- 分片大小波动极大，**取平均数会偏**（单节实测误差可达 ±167%），所以用**中位数**；
- 结果带缓存，同一节课重复估算不会重跑；
- 支持后台取消，估错了随时停。

精度实测（52 节真实下载对比）：**合计估算 57.6 GB vs 实际 51.6 GB，误差 +11.7%**，方向偏保守。

## 常见问题

**Q：页面提示「本地服务未启动」？**
先跑 `start.py`（或双击 `一键启动.bat`），确认浏览器能打开 <http://127.0.0.1:8777/>。

**Q：点「读取目录」报错 / 读不到课时？**
① 确认你当前标签页是**已登录**的小鹅通店铺页面；② 确认这门课在你的「我的」里可见；③ 换个页面再点一次（扩展只在你主动点击时工作）。

**Q：课时列表出来了，但「播放地址」全是空的 / 提示要登录？**
目录和课件**免登录**就能读，**播放地址必须登录**（实测未登录返回 `code:11302`）。
所以这说明：**你的取数页面不是登录态**。请：

1. 确认当前小鹅通页面右上角显示的是**你的账号**（不是「登录」按钮）；
2. 在同一个标签页重新执行一次取数；
3. 扩展弹窗里展开「诊断 trace」能看到每个接口的真实返回码和错误码，按它定位。

> 常见误判：Edge / Chrome 里打开过小鹅通 ≠ 已登录。游客态只有 `anony_token`，
> 登录态才有 `user_id` + `ANONYLOGON:0`。以页面上有没有账号昵称为准。

**Q：提示「⚠ 未找到 ffmpeg」？**
没装 ffmpeg 就无法合并与校验视频。装好后**重启**控制台。

**Q：视频合并后 ffprobe 报错？**
下载器会自动重试 3 轮：重新拉全部分片 → 重新合并 → 重新校验。3 轮都不过会在日志里写明原因。

**Q：录播下载失败，提示签名过期？**
录播地址是 AES-128 加密清单，签名约 30 分钟过期。重新在扩展里点一次「读取目录」刷新地址，再开始下载（下载器是**现取现用**的）。

**Q：会被平台发现吗？**
工具只调用平台自己页面上的接口，且流量从你本机发出。**平台可能随时改接口，工具随时可能失效**——请尊重平台规则，不要用来下载你无权下载的内容。
