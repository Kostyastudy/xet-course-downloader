# 小鹅通课程下载器 · xet-course-downloader

把「小鹅通店铺里的课程」完整搬到本地：**读目录 → 下分片 → 合并成完整视频 → 下课件 → 整理成目录**。

一个**本地网页控制台** + 一个**极小的浏览器扩展**，零第三方 Python 依赖。

## 它长什么样

```
┌──────────────┐   ①在已登录页面里读目录      ┌──────────────────┐
│  浏览器扩展   │ ─────────────────────────▶ │   本地服务        │
│  或控制台一行 │   只取目录 + 签名播放地址    │  127.0.0.1:8777  │
└──────────────┘                            └────────┬─────────┘
                                                       │ ②计划(JSON)
                                                       ▼
                                              ┌──────────────────┐
                                              │  网页控制台       │
                                              │  勾选课时/看进度  │
                                              └────────┬─────────┘
                                                       │ ③全部字节走本地
                                                       ▼
                                     ┌────────────────────────────────┐
                                     │  Python 下载器（零依赖）         │
                                     │  分片并发 → concat → ffprobe 自检 │
                                     │  → 课件下载 → 按名归档 → 索引      │
                                     └────────────────────────────────┘
```

**关键设计**：扩展/控制台桥**只负责取数**（目录 + 签名地址），**几十 GB 的实际流量、合并、校验、归档全走本地 Python**。视频分片与课件 CDN 直链免登录可下，所以浏览器不需要经手任何大文件。

**关键隐私**：扩展**不读取、不存储、不外传你的 Cookie / 账号信息**。它只是在你已登录的页面里，用浏览器本来就有的登录态调平台自己的接口。

## 快速开始（Windows）

1. 装好 Python 3.8+（安装时勾选 *Add python.exe to PATH*）和 ffmpeg。
2. **双击 `一键启动.bat`**。
   浏览器会自动打开 <http://127.0.0.1:8777/>。
3. 按页面上的指引装一次「取数桥」（下面两种任选）。

> macOS / Linux：`python3 start.py`

## 三步用法

### ① 装「取数桥」（只需一次）

下载器只负责搬字节；**「拿课程目录 + 签名播放地址」这一步必须在你自己已登录的小鹅通页面里执行**。两种方式任选：

**方式 A · 浏览器扩展（推荐）**

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目的 **`extension/`** 目录
4. 登录你的小鹅通店铺页面，点工具栏里的扩展图标

**方式 B · 一行控制台命令（不想装扩展）**

在你**已登录**的小鹅通课程页按 `F12` → 控制台，粘贴：

```js
fetch('http://127.0.0.1:8777/bridge.js').then(r=>r.text()).then(eval)
```

执行后回到控制台页面刷新，就能看到课时列表了。
（换浏览器 / 换店铺要重来一次；想指定课程链接用
`fetch('http://127.0.0.1:8777/bridge.js?url=' + encodeURIComponent('你的课程链接')).then(r=>r.text()).then(eval)`）

> 扩展和控制台桥跑的是**同一份** `extension/content.js`（本地服务在 `/bridge.js` 下发它），
> 所以两条路的行为完全一致，不会出现「扩展能下、控制台桥不能下」这种跑偏。

### ② 选课、下载

在控制台页面：

- 扩展方式：点扩展图标 →「读取目录」→ 勾选 →「同步到下载器」→ 回控制台页面
- 控制台桥方式：页面会自动刷新出课程列表

然后勾选要下的课时，点「**开始下载**」，填保存目录。

### ③ 看进度

页面下方「任务进度」区实时显示每讲的进度条、日志和「打开目录」按钮。任务可以随时取消；重跑同一门课会自动跳过已存在的视频（断点续跑）。

## 输出目录结构

```
<保存目录>/
└── <课程名>/
    ├── 00_课程总览.md          ← 全部课时的索引表（视频/课件/状态）
    ├── 使用须知.md              ← 合规提示，随产物一起走
    ├── 下载计划.json            ← 本次下载计划，可给命令行模式复用

    │   └── 课件/                ← 按文件名自动对号入座的课件
    ├── 02_第2讲/
    │   ├── 视频.mp4
    │   └── 课件/
    └── ...
```

课件会按**文件名里的日期 / 第 N 讲 / NN 课 / 第 N 章**自动分发到对应课时；同盘默认用**硬链接**，不额外占磁盘空间。

## 无界面 / 服务器用法

把控制台页面里的计划存成 JSON（下载目录下的 `下载计划.json` 就是），可以直接在命令行跑：

```bash
python start.py --run 下载计划.json --out "D:\课程" --jobs 2 --threads 10
```

校验已归档的成片：

```bash
python start.py --verify "D:\课程"
```

> 在项目目录下也可以用 `python -m xetdl.cli verify "D:\课程"`。

## 平台接口实测结论（2026-11-17 真实抓包）

工具的取数逻辑全部基于对真实小鹅通店铺的实测，不是猜的。**哪些接口要登录、哪些不要**，这一节是整份文档里最该先读的：

| 接口 | 用途 | 免登录？ |
|---|---|---|
| `/xe.course.business_go.column.items.get/2.0.0` | 读专栏的课时列表 | ✅ **公开可读**，匿名也能拿全量 list |
| `/xe.course.business_go.courseware_list.get/2.0.0` | 读课件附件清单 | ✅ 免登录，CDN 直链 |
| `/xe.micro_page.category_good.get/2.0.0` | 读店铺商品清单 | ✅ 免登录（`category_goods_id` 必须是**字符串**） |
| `/xe.course.business_go.goods.info.get/2.0.0` | 读大课包商品信息 | ✅ 免登录，但参数名是 **`resource_id`**（传 `product_id` 报 `code:10 参数错误`） |
| `/_alive/v3/get_lookback_list?alive_id=…` | 直播回放 → 播放地址 | ❌ **需要登录**，未登录返回 `code:11302` |
| `/xe.course.business_go.video.mutli_line/1.0.0` | 录播 → 播放地址 | ❌ **需要登录**（AES-128 加密清单，约 30 分钟过期） |

**所以**：**目录和课件不用登录就能读全，只有「播放地址」这一步需要登录态**。
这也是为什么工具把取数拆成两段（`withUrls` / `withWare` 可单独开关）——
没登录也能先把「这门课有多少节、叫什么」看清楚。

**大课包（一个专栏点进去是多个子专栏）**：
`column.items.get` 对大课包会返回 `code:0` 但 `list` 为空，子专栏在 `goods.info.get` /
`resource.available.get` 里。工具会先试目录、发现列表为空就自动转去商品信息分支，
再用递归结构提取找出所有 `p_` 开头的子专栏 id（不依赖字段名，平台改字段也不会失效）。

## 常见问题

**Q：页面提示「本地服务未启动」？**
先跑 `start.py`（或双击 `一键启动.bat`），确认浏览器能打开 <http://127.0.0.1:8777/>。

**Q：点「读取目录」报错 / 读不到课时？**
① 确认你当前标签页是**已登录**的小鹅通店铺页面；② 确认这门课在你的「我的」里可见；③ 换个页面再点一次（扩展只在你主动点击时工作）。

**Q：课时列表出来了，但「播放地址」全是空的 / 提示要登录？**
目录和课件**免登录**就能读，**播放地址必须登录**（实测未登录返回 `code:11302`）。
所以这说明：**你的取数页面不是登录态**。请：

1. 确认当前小鹅通页面右上角显示的是**你的账号**（不是「登录」按钮）；
2. 在同一个标签页重新执行一次取数；
3. 扩展弹窗里展开「诊断 trace」能看到每个接口的真实返回码和错误码，按它定位。

> 常见误判：Edge / Chrome 里打开过小鹅通 ≠ 已登录。游客态只有 `anony_token`，
> 登录态才有 `user_id` + `ANONYLOGON:0`。以页面上有没有账号昵称为准。

**Q：提示「⚠ 未找到 ffmpeg」？**
没装 ffmpeg 就无法合并与校验视频。装好后**重启**控制台。

**Q：视频合并后 ffprobe 报错？**
下载器会自动重试 3 轮：重新拉全部分片 → 重新合并 → 重新校验。3 轮都不过会在日志里写明原因。

**Q：录播下载失败，提示签名过期？**
录播地址是 AES-128 加密清单，签名约 30 分钟过期。重新在扩展里点一次「读取目录」刷新地址，再开始下载（下载器是**现取现用**的）。

**Q：会被平台发现吗？**
工具只调用平台自己页面上的接口，且流量从你本机发出。**平台可能随时改接口，工具随时可能失效**——请尊重平台规则，不要用来下载你无权下载的内容。
