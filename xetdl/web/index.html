① 让下载器拿到你的课程目录只需一次

下载器只负责搬字节。「课程目录 + 带签名的播放地址」必须在你已登录的小鹅通页面里取，两种方式任选其一。

方式 A · 浏览器扩展推荐

  1. 打开 edge://extensions（Chrome 是 chrome://extensions）
  2. 打开「开发者模式」
  3. 点「加载已解压的扩展程序」→ 选择项目里的 extension 目录
  4. 在小鹅通页面点工具栏扩展图标 →「读取目录」→「同步到下载器」

扩展只做取数，不保存账号、拿不到 Cookie。
