① 装好"取数桥"（只需一次）

下载器只负责搬运字节；「拿课程目录 + 签名播放地址」这一步必须在你已登录的小鹅通页面里执行。两种方式任选其一：

方式 A · 浏览器扩展推荐

  1. 打开 Chrome / Edge → chrome://extensions（Edge 是 edge://extensions）
  2. 打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选择本项目的 extension/ 目录
  4. 登录你的小鹅通店铺页面，点工具栏里的扩展图标

扩展只做一件事：在登录页面里替你调用接口取目录和播放地址。它不保存任何账号信息，也拿不到你的 Cookie。
